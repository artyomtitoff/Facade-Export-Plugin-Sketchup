# Соответствие задания и реализации

Пошаговая сверка ТЗ «Экспорт фасадов» с кодом. Формулировки задания — слева.

## 0. Подготовка

| Задание | Реализация |
|---------|------------|
| Пользователь выравнивает вид перпендикулярно плоскости фасада | Не требуется ничего со стороны плагина; направление взгляда читается из камеры (`Framing.horizontal_direction`). Если вид вертикальный (сверху/снизу) или сильно наклонён — плагин просит выровнять вид. |

## Кнопки

| Задание | Реализация |
|---------|------------|
| Две кнопки: «Экспорт всех фасадов», «Экспорт фасада» | Панель инструментов «Экспорт фасадов» + меню «Расширения → Экспорт фасадов» (`main.rb#register_ui`) |
| Разработать иконки | `facade_export/icons/export_all_{24,32}.png`, `export_one_{24,32}.png`, `settings_{24,32}.png`; генератор `tools/make_icons.py`, превью `docs/icons_preview.png` |

## 1. Общий стиль для всего экспорта

| Требование | Ключ / метод |
|------------|--------------|
| Вид → скрыть направляющие | `HideConstructionGeometry = true` |
| Правка → Фон → убрать небо и землю | `DrawSky = false`, `DrawGround = false`, `DrawHorizon = false` |
| Фон RGB 255,255,255 | `BackgroundColor`, `SkyColor`, `GroundColor` = `Color(255,255,255)` |
| Правка → Край → убрать профили, показ глубин, расширение, конечные точки, дрожание, пунктир | `DrawProfilesOnly`, `DrawDepthQue`, `ExtendLines`, `DrawLineEnds`, `JitterEdges`, `DisplayLineStyles` = `false` (дополнительно `DrawSilhouettes = false`, `EdgeType = 0`) |
| Правка → Грань → убрать задние рёбра и рентген | `DrawBackEdges = false`, `ModelTransparency = false` |
| Тени → убрать «Использовать солнце для затенения» | `UseSunForAllShading = false` |
| Камера → параллельная проекция | `camera.perspective = false` |

Дополнительно (чтобы в кадр не попадала служебная графика): `DrawHidden = false`,
`DisplaySketchAxes = false`, `DisplayInstanceAxes = false`, `DisplayText = false`,
`DisplayDims = false`, `DisplayWatermarks = false`, `DisplayFog = false`,
`DisplaySectionCuts = false`, `DisplaySectionPlanes = false`, `ShowViewName = false`,
а также снимается выделение (подсветка выделенного попадает в `write_image`).

## 2. Автоматическое масштабирование

| Требование | Реализация |
|------------|------------|
| Весь фасад влезает целиком | `Framing.plan_fit` — проекция 8 углов габаритного ящика на плоскость кадра, отступ 4 % (`export.margin`) |
| (шаг 4) новый фасад в том же масштабе | Одна и та же высота ортокадра `plan[:height]` для всех четырёх камер |

## 3. Карты

### 3.1 Текстура

| Требование | Реализация |
|------------|------------|
| Правка → Грань → «Затенение с текстурами» | `RenderMode = 2`, `Texture = true` |
| Прозрачность материала убрать | `MaterialTransparency = false` |
| Правка → Край → скрыть края | `EdgeDisplayMode = 0` |
| Экспорт PNG | `View#write_image` |

### 3.2 Линии

| Требование | Реализация |
|------------|------------|
| Правка → Край → показать края | `EdgeDisplayMode = 1` |
| Правка → Грань → «Скрытые линии» | `RenderMode = 1` |

### 3.3 Тени

| Требование | Реализация |
|------------|------------|
| Правка → Край → скрыть края | `EdgeDisplayMode = 0` |
| Тени по принципу Elevation 45 Shadows (left) | `Sun.setup`: подмена геолокации/времени, подбор `NorthAngle` и `Latitude` по фактическому `SunDirection`; резерв — оригинальная формула TIG (`Sun.legacy_north_angle`) |
| «Светлее» 100, «Темнее» 0 | `ShadowInfo['Light'] = 100`, `['Dark'] = 0` |
| «Использовать солнце для затенения» не включается | `UseSunForAllShading = false` на каждом шаге |
| Грани белые, чтобы остались только тени | `RenderMode = 1` (скрытые линии, без текстур) |

### 3.4 Окна

| Требование | Реализация |
|------------|------------|
| Отключить тени | `DisplayShadows = false` |
| Правка → Грань → «Отобразить в режиме теней» | `RenderMode = 2` |
| Материалы с непрозрачностью ≠ 100 % → H 125 / S 100 / L 50 | `GlassRecolor#apply`: `texture = nil`, `color = HSL(125,100,50)`, `alpha = 1.0` |
| Контраст к фону | H 125 / S 100 / L 50 = RGB(0, 255, 21) — яркий акцент на белом фоне и на прозрачном PNG |

### 3.5 Возврат цветов

| Требование | Реализация |
|------------|------------|
| Вернуть прозрачным материалам исходный цвет | `GlassRecolor#restore` (цвет + альфа + путь к текстуре) |

## 4, 6, 8. Поворот камеры на 90°

| Требование | Реализация |
|------------|------------|
| Разворот на 90° на следующий фасад | `Framing.facade_directions` — `rotate_90` горизонтального направления взгляда |
| Фасад целиком в кадре | Тот же расчёт кадра, что и для первого фасада (`plan_fit` по всем направлениям сразу) |
| Тот же масштаб | `camera.height` одинаковый у всех четырёх камер |

## 5, 7, 9. Экспорт карт следующих фасадов

| Требование | Реализация |
|------------|------------|
| Аналогично п. 3 для каждого фасада | Цикл `@facade_count.times` × `maps.each` в `Exporter#run` |

## 10. Возврат настроек

| Требование | Реализация |
|------------|------------|
| Вернуть всё как в п. 0 | `SceneState`: снимок `rendering_options`, `shadow_info` и камеры до начала работы, восстановление в `ensure` (работает и при ошибке); выделение и текст строки состояния тоже возвращаются |

## Главное: работа «за кадром»

| Требование | Реализация |
|------------|------------|
| Пользователь не видит промежуточных состояний, не нагружается процессор | Все 16 изображений пишутся через `View#write_image` (рендер в память, окно просмотра не меняет размер); Ruby не отдаёт управление до конца операции, поэтому SketchUp не перерисовывает вид; после экспорта камера, стиль и тени возвращаются — пользователь продолжает с того же вида |
| Максимально быстрая работа | (1) без перерисовок вьюпорта и без `zoom_extents`; (2) стиль меняется только по отличающимся ключам (`OptionBag#apply`); (3) настройки солнца калибруются за несколько итераций, а не пересчётом всей сцены; (4) материалы перекрашиваются один раз на карту «Окна», а не на каждый фасад; (5) изображения пишутся без сглаживания (оно дороже всего) и без сжатия в памяти; (6) `File.delete` перед записью — без диалогов подтверждения |

## Параметры экспорта по умолчанию

| Требование | Значение в `Config.default_settings` |
|------------|--------------------------------------|
| Тип файла PNG | Расширение `.png` |
| Не использовать размер вида | `use_view_size = false` |
| Ширина 9999 пикс. | `width = 9999` |
| Высота автоматически | `height = 0` → `width × vpheight / vpwidth` |
| Множитель масштаба линии 0,3x | `line_scale = 0.3` (`:scale_factor`) |
| Автоматическое сглаживание убрать | `antialias = false` |
| Прозрачный фон включить | `transparent = true` |
| Имя файла | `Имя_Фасад_НомерФасада_НазваниеКарты.png` (`Exporter.file_name`) |
| Спрашивать только путь сохранения | `UI.savepanel` один раз; настройки применяются ко всем изображениям |

## Совместимость

| Требование | Реализация |
|------------|------------|
| SketchUp 2021, 2025 и выше | Ключи стиля пишутся только при их наличии (`RenderingOptions#keys`), запись обёрнута в `rescue` (в 2024+ неизвестный ключ — `ArgumentError`); `:scale_factor` в `write_image` пробуется с откатом для старых версий; нет вызовов API новее 2020; `frozen_string_literal` не используется, поэтому строки можно менять на месте. |
