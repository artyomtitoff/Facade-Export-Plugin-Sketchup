# Экспорт фасадов — плагин для SketchUp

Автоматический экспорт 2D-геометрии фасадов в PNG: **4 фасада × 4 визуальные карты = 16 изображений** по нажатию одной кнопки.

**Автор:** Артем Титов — `motivate_rt`
**Версия:** 1.0.0
**SketchUp:** 2021, 2025 и новее (Windows и macOS)

> **Быстрая установка:** взять [`dist/FacadeExport_v1.0.0.rbz`](dist/FacadeExport_v1.0.0.rbz)
> и в SketchUp выполнить **Окно → Менеджер расширений → Установить расширение…**

## Что делает плагин

Пользователь выравнивает вид перпендикулярно фасаду и нажимает кнопку. Плагин сам:

* настраивает стиль отображения (фон, рёбра, грани, направляющие, тени, параллельная проекция);
* масштабирует вид так, чтобы фасад целиком попал в кадр;
* поворачивает камеру на 90° на каждый следующий фасад, сохраняя **один и тот же масштаб**;
* для каждого фасада экспортирует 4 PNG-карты;
* возвращает стиль, тени и камеру пользователя в исходное состояние.

В результате в выбранной папке появляется 16 файлов:

```
Имя_Фасад_1_Текстура.png     Имя_Фасад_2_Текстура.png     Имя_Фасад_3_Текстура.png     Имя_Фасад_4_Текстура.png
Имя_Фасад_1_Линии.png        Имя_Фасад_2_Линии.png        Имя_Фасад_3_Линии.png        Имя_Фасад_4_Линии.png
Имя_Фасад_1_Тени.png         Имя_Фасад_2_Тени.png         Имя_Фасад_3_Тени.png         Имя_Фасад_4_Тени.png
Имя_Фасад_1_Окна.png         Имя_Фасад_2_Окна.png         Имя_Фасад_3_Окна.png         Имя_Фасад_4_Окна.png
```

Пример: `Заречная_Фасад_1_Текстура.png`.

| Карта | Что на ней | Как получено |
|-------|------------|--------------|
| **Текстура** | только текстуры материалов, без линий | Затенение, текстуры включены, края скрыты, прозрачность материала выключена |
| **Линии** | только линии | Скрытые линии, края показаны |
| **Тени** | только тени под 45° слева сверху | Белые грани без краёв + тени, солнце 45°/45°, «светлее» 100, «темнее» 0 |
| **Окна** | все стеклянные (прозрачные) поверхности контрастным цветом | Тени выключены, «затенение», прозрачные материалы перекрашены в H 125 / S 100 / L 50 |

## Установка

### Вариант 1. Файл `.rbz` (проще всего)

1. Взять готовый архив `dist/FacadeExport_v1.0.0.rbz` из этого репозитория
   (или собрать его самому: `python3 tools/build_rbz.py`).
2. В SketchUp: **Окно → Менеджер расширений → Установить расширение…** и выбрать `.rbz`.
3. Согласиться с предупреждением и перезапустить SketchUp.
4. Появится панель инструментов **«Экспорт фасадов»** и меню
   **Расширения → Экспорт фасадов**.

### Вариант 2. Вручную (для разработки)

Скопировать в папку `Plugins` SketchUp:

```
Plugins/
├── facade_export.rb          ← загрузчик расширения (лежит в корне репозитория)
└── facade_export/            ← папка плагина целиком
    ├── main.rb
    ├── config.rb
    ├── util.rb
    ├── scene_state.rb
    ├── framing.rb
    ├── sun.rb
    ├── glass.rb
    ├── exporter.rb
    ├── dialogs.rb
    ├── html/settings.html
    └── icons/*.png
```

Путь к `Plugins`:
* Windows: `%AppData%\SketchUp\SketchUp 20XX\SketchUp\Plugins`
* macOS: `~/Library/Application Support/SketchUp 20XX/SketchUp/Plugins`

После правки Ruby-файлов достаточно перезапустить SketchUp (или выполнить
`FacadeExport.register_ui` заново в консоли Ruby).

## Как пользоваться

1. Открыть модель.
2. Выровнять вид **перпендикулярно основной плоскости фасада**
   (Камера → Стандартные виды, либо правый клик по грани → «Выровнять вид»).
   Плагин ничего не требует от этого шага, но именно от этого вида считаются все четыре фасада.
3. Нажать:
   * **Экспорт всех фасадов** — 4 фасада × 4 карты = 16 PNG;
   * **Экспорт фасада** — только текущий фасад = 4 PNG.
4. В появившемся окне выбрать **папку и имя файла** (как в штатном экспорте
   SketchUp). Из имени берётся префикс, из папки — куда сохранять.
   Настройки экспорта уже выставлены по заданию и спрашиваются один раз:
   * тип файла — PNG;
   * «Не использовать размер вида»;
   * ширина **9999** пикселей, высота — автоматически (по пропорциям окна просмотра);
   * множитель масштаба линии **0,3x**;
   * «Автоматическое сглаживание» — выключено;
   * «Прозрачный фон» — включён.
5. Плагин экспортирует изображения «за кадром» и показывает отчёт:
   сколько файлов, за какое время, среднее время на изображение, объём.
6. Вид, стиль, тени и камера возвращаются к тому состоянию, в котором пользователь
   нажимал кнопку — можно продолжать работу.

Кнопки:

| Кнопка | Действие |
|--------|----------|
| ![Экспорт всех фасадов](facade_export/icons/export_all_32.png) **Экспорт всех фасадов** | 4 фасада × 4 карты = 16 PNG |
| ![Экспорт фасада](facade_export/icons/export_one_32.png) **Экспорт фасада** | 4 карты текущего вида = 4 PNG |
| ![Настройки](facade_export/icons/settings_32.png) **Настройки…** | окно настроек карт и экспорта (только в меню и панели, не считается кнопкой экспорта) |

## Что именно настраивает плагин

### Общие настройки стиля для всего экспорта (шаг 1 задания)

| Требование задания | Реализация |
|--------------------|------------|
| Вид: скрыть направляющие | `HideConstructionGeometry = true` |
| Правка → Фон: убрать небо и землю | `DrawSky = false`, `DrawGround = false`, `DrawHorizon = false` |
| Фон RGB 255,255,255 | `BackgroundColor`, `SkyColor`, `GroundColor` = белый |
| Правка → Край: убрать профили, показ глубин, расширение, конечные точки, дрожание, пунктир | `DrawProfilesOnly`, `DrawDepthQue`, `ExtendLines`, `DrawLineEnds`, `JitterEdges`, `DisplayLineStyles` = false (+ силуэты) |
| Правка → Грань: убрать задние рёбра и рентген | `DrawBackEdges = false`, `ModelTransparency = false` |
| Тени: не использовать солнце для затенения | `UseSunForAllShading = false` |
| Камера: параллельная проекция | `camera.perspective = false` |
| Масштабировать так, чтобы фасад влез целиком | своя компоновка кадра (см. ниже) |

### Карты (шаг 3 задания)

| Карта | Режим отображения | Края | Тени | Особое |
|-------|-------------------|------|------|--------|
| Текстура | Затенение (`RenderMode = 2`) + текстуры | скрыты (`EdgeDisplayMode = 0`) | выключены | прозрачность материала выключена |
| Линии | Скрытые линии (`RenderMode = 1`) | показаны (`EdgeDisplayMode = 1`) | выключены | — |
| Тени | `RenderMode = 1` (грани белые) | скрыты | **включены**: солнце 45° слева сверху, «светлее» 100, «темнее» 0, солнце для затенения выключено | позиция солнца подгоняется под вид |
| Окна | `RenderMode = 2` (без текстур) | скрыты | выключены | материалы с непрозрачностью < 100 % перекрашиваются в HLS 125/100/50, после экспорта цвет возвращается |

### Поворот камеры (шаги 4, 6, 8, 10 задания)

Каждый следующий фасад — поворот горизонтального направления взгляда на 90°.
Считается один общий ортографический масштаб: высота кадра = максимум из
(высота самого высокого фасада) и (ширина самого широкого фасада / соотношение сторон).
Поэтому все четыре фасада получаются **в одном масштабе** и ни один не обрезается.
После четвёртого фасада вид, стиль и тени возвращаются в исходное состояние.

## Настройки плагина

**Расширения → Экспорт фасадов → Настройки…** (или кнопка с шестерёнкой).

Значения по умолчанию соответствуют заданию; всё можно изменить:

* **Экспорт** — ширина/высота, множитель линий, сглаживание, прозрачный фон,
  «не использовать размер вида», отступ вокруг фасада, параллельная проекция;
* **Стиль** — оставлять ли небо/землю, скрывать направляющие и водяные знаки,
  отключать плоскости сечения, «светлее»/«темнее», «использовать солнце для затенения»;
* **Поведение** — возвращать ли вид и стиль, показывать ли отчёт;
* **Каждая карта отдельно** — название (попадает в имя файла), режим отображения,
  текстуры, края, тени, прозрачность материала, «солнце для затенения»,
  «светлее»/«темнее», азимут и высота солнца, перекраска прозрачных материалов и цвет HLS.

Настройки хранятся в `Sketchup.read_default/write_default` (раздел `FacadeExport`),
т.е. переживают перезапуск SketchUp.

Посмотреть, как выглядит окно, можно без SketchUp:
[`docs/settings_preview.html`](docs/settings_preview.html).

Дополнительные материалы в `docs/`:

* [`docs/checklist.md`](docs/checklist.md) — сверка ТЗ и реализации пункт за пунктом;
* [`docs/maps_scheme.png`](docs/maps_scheme.png) — схема 16 изображений;
* [`docs/icons_preview.png`](docs/icons_preview.png) — иконки кнопок в 24 и 32 px.

## Как это работает внутри

### 1. Экспорт без перерисовки вьюпорта

Все изображения пишутся через `Sketchup::View#write_image` в режиме рендера «за кадром»:
SketchUp рисует кадр нужного размера в память и сохраняет PNG. Окно просмотра
не меняет размер, не мигает и не перерисовывается 16 раз — интерфейс не «дёргается»,
процессор не тратится на лишние кадры. Размер изображения (9999 × H) берётся из
настроек экспорта, а не из окна.

### 2. Минимум изменений стиля

Для каждой карты сравниваются текущие значения с нужными, и записываются
**только отличающиеся** параметры (`OptionBag#apply`). Ключи, которых нет в данной
версии SketchUp, пропускаются (`RenderingOptions#keys`), поэтому плагин одинаково
работает в 2021 и в 2025+, где запись неизвестного ключа уже выбрасывает `ArgumentError`.

### 3. Тени 45° слева сверху

Использован принцип плагина **Elevation 45 Shadows** (TIG): «география» модели
(широта, долгота, часовой пояс, время) подменяется так, чтобы солнце встало
в нужную точку, а `NorthAngle` разворачивает его относительно вида.

Отличие в реализации: вместо готовой формулы угол **калибруется по факту**.
Плагин ставит пробное значение `NorthAngle`, читает фактический `SunDirection`,
считает масштаб отклика и итеративно подбирает `NorthAngle` и `Latitude` так,
чтобы солнце оказалось точно под 45° к фасаду и на высоте 45° (тени падают
вправо-вниз под 45°). Если `SunDirection` недоступен, используется оригинальная
формула TIG. После экспорта все настройки теней возвращаются.

### 4. Единый масштаб

Для каждого направления взгляда считается проекция восьми углов габаритного
ящика модели; из них выбирается требуемая высота ортокадра
(`max(высота, ширина / aspect) / (1 − отступ)`), одна на все фасады.
Цель камеры ставится в центр проекции фасада, камера отодвигается на
безопасное расстояние (чтобы не сработало отсечение).

### 5. Перекраска стекла

Материалы с непрозрачностью меньше 100 % (включая материалы с текстурой)
получают цвет H 125 / S 100 / L 50 и непрозрачность 100 %, текстура снимается.
После кадра «Окна» всё возвращается: цвет, альфа и путь к текстуре.

### 6. Восстановление состояния

Перед началом работы снимается полный снимок `model.rendering_options`,
`model.shadow_info` и камеры (eye/target/up, тип проекции, fov или height).
По завершении (в том числе при ошибке) снимок применяется обратно.

## Важные замечания и ограничения

* **Тени есть только на карте «Тени».** В задании карты «Текстура» и «Линии»
  описаны как «только текстуры без линий» и «только линии», поэтому тени на них
  выключены (как и в шаге 3.4 для карты «Окна»). Если нужны тени на текстурах —
  включите «Тени» у карты «Текстура» в настройках.
* **Стиль меняется у активного стиля модели.** Плагин восстанавливает параметры
  стиля после экспорта, но если модель использует сцены (Pages) со своими стилями,
  изменения затрагивают именно текущий активный стиль. Если не хотите, чтобы
  обновлённые параметры сохранились в файле после сохранения модели, работайте
  на копии или не сохраняйте модель после экспорта.
* **Солнце и геолокация.** Для точных теней плагин временно меняет
  «Модель → Сведения о модели → Географическое положение» (широту, долготу,
  часовой пояс, время). После экспорта значения возвращаются.
* **Геометрия.** Модель должна быть повёрнута так, чтобы её оси совпадали
  с фасадами (стандартный случай). Плагин поворачивает камеру вокруг вертикальной
  оси, поэтому фасады считаются «осевыми»: ±X и ±Y.
* **Вид сверху/снизу** не подходит: плагин сообщит, что нужно выровнять вид
  перпендикулярно фасаду.
* **Размер 9999 px** — значение по умолчанию; SketchUp ограничивает изображение
  16000 px по стороне, плагин дополнительно проверяет диапазон.
* **Прозрачный фон** включён, поэтому белый фон нужен только для просмотра;
  в PNG он прозрачный (как в штатном экспорте с этой галочкой).
* Панель инструментов и меню доступны и в русской, и в английской локализации
  SketchUp (названия заданы строками плагина, а не системными ресурсами).

## Тесты и сборка

Логика плагина покрыта автотестами, которые запускаются **без SketchUp**:

* `test/run.mjs` — Ruby-код исполняется в WebAssembly-версии Ruby поверх
  заглушки SketchUp API (`test/mock_sketchup.rb`): 148 проверок;
* `test/settings_ui.test.mjs` — окно настроек открывается в jsdom и проверяется
  вместе с обменом данными через `UI::HtmlDialog`.

```bash
npm install          # Ruby-WASM + jsdom
npm test             # оба набора тестов
```

Проверяется, в частности: синтаксис всех Ruby-файлов, направления четырёх
фасадов, единый масштаб кадра, точность солнца 45°/45° для каждого фасада,
режимы и края каждой карты, перекраска и восстановление материалов, снятие и
возврат выделения, полный набор из 16 файлов с правильными именами,
восстановление стиля/теней/камеры, отмена выбора папки, сообщения об ошибках,
значения по умолчанию в окне настроек и сохранение изменённых параметров.

Сборка `.rbz`:

```bash
python3 tools/build_rbz.py       # -> dist/FacadeExport_v1.0.0.rbz
python3 tools/make_icons.py      # перерисовать иконки
```
